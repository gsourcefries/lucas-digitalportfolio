LUKE ANDREI P. DELA CRUZ — DIGITAL PORTFOLIO

FILES
- index.html: portfolio page
- style.css: responsive styling
- script.js: mobile navigation and footer year
- assets/profile.jpg: profile portrait
- assets/LukeAndrei_DelaCruz_IT_OJT_Resume.pdf: downloadable resume

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open the luke-andrei-portfolio folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

PUBLISHING
This is a static website and can be hosted free on GitHub Pages or Netlify.
For GitHub Pages: create a public repository, upload the CONTENTS of this folder,
then open Settings > Pages and select Deploy from a branch (main / root).
GitHub will provide the public website URL after deployment.
